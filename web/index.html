How to play OL FreeCell

  • Build the four foundations up by suit from Ace to King.
  • Cascades build down by alternating colour. You can move a properly-built run when enough freecells and empty cascades free it.
  • The four freecells each hold a single card.
  • Drag a card or built stack onto a cascade, freecell, or foundation. Only legal drops stick.
  • Every daily deal is proven solvable by an in-app solver before you see it — it is always winnable.
